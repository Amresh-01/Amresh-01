- **Data Generation**: Synthetic data generation with SDV and CTGAN, tabular modeling
- **Security & Fraud**: Fraud detection, biometric verification, deepfake/catfish detection

- **MLOps**: End-to-end deployment with Docker, RunPod, API integrations, cloud tooling
